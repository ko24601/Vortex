YOUR STORE — first mobile prototype

Included:
- Product catalog with the 3 supplied products, all €200
- Search and category filters
- Product details
- Basket with quantities and running total
- Quick Add Product flow with photo upload
- Payments intentionally not connected yet

To test:
1. Unzip the folder.
2. Open index.html in a modern browser.
3. For the best phone-like experience, serve the folder from a simple local web server.
4. The app is structured as a PWA shell, ready for the next packaging step for iPhone/Android.

Note: newly added products are kept in the current browser session; a production version should add persistent cloud storage and an admin/catalog backend.
